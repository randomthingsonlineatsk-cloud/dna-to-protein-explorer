# DNA to Protein Explorer

Click a base to mutate it and watch transcription and translation update.

**Live demo:** https://macaly-lv4a66ho9ak5b6860z9eym5z-prod.macaly-app.com

> This is a fictional, educational demonstration. Do not use it for real patient data, clinical decisions or regulatory submissions.

## Features
- Mutation classification: silent, missense, nonsense, stop-loss, frameshift, in-frame indel, no effect
- Mutation quiz with a leaderboard
- Sequence and protein analysis tools, codon wheel, practice and flashcard modes

## Tech stack
TanStack Start, React, Tailwind CSS, Convex (leaderboard). Built on Macaly Cloud.
